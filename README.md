# Barbers Go

Aplicação para Agendamento de serviços em barbearias.

## Funcionalidades

### Home

- Agendamentos
- Recomendados
- Populares

### Detalhes da Barbearia

- Localização
- Avaliação
- Serviços/valores
- Contato

### Reserva

Escolha do serviço, data e hora disponivel.

### Agendamentos

- Confirmados
  - Detalhes da reserva
    - Endereço / Data / Contato
  - Alterar agendamento(max. 12h antes)
  - Cancelar reserva

- Finalizados
  - Avaliar Atendimento
  - Novo agendamento

## Run Project

```bash
# bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
